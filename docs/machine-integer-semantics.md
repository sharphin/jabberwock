# 固定幅整数の形式仕様と未完了の実装対応

2026-10-27。PR #30 の第1機構「コンパイラ全体の数学的対応証明」の部分実装。
**機構の完成数は引き続き 0/4。Lean の実行確認も未実施。**

`formal/JabberwockFormal/MachineIntegers.lean` は、既存の `ScopedGoals.lean` の
`Nat` による加算とは別に、実言語の整数値に必要な規則を記述する。
既存の限定モデルを実装証明に昇格させず、共有仕様として扱う。
同じ言語仕様を使っても、jwc と Rust の対応証明は別々に必要である。

## 定義した規則

| 規則 | Lean の定義・定理 | 根拠と範囲 |
|---|---|---|
| 整数9型 | `IntTy`, `bits`, `signed`, `InRange` | i8/i16/i32/i64、u8/u16/u32/u64、64-bit usize |
| 幅による一周 | `wrap`, `wrap_in_range`, `wrap_eq_self`, `wrap_idempotent` | 数学的整数を型の値域へ正規化する。定理は全入力について記述 |
| 明示的な整数変換 | `cast` | 変換先の幅で丸める。浮動小数点変換は未対応 |
| 暗黙の整数変換 | `widensTo`, `common`, `widening_preserves_range`, `widening_preserves_value` | usize を u64 と区別し、許された変換で値を保存 |
| 加減乗算 | `arithmetic` | 数学的整数で計算して幅で丸める |
| ビット演算・反転 | `bitwise`, `complement` | 符号付き整数のビット操作を行い、幅で丸める |
| 単項マイナス | `negate` | 符号付き型であることを静的な前提にする |
| 大小・等値比較 | `compare` | 同じ型に揃えた値の比較 |
| 除算・剰余 | `quotient`, `quotient_success_iff` | ゼロはエラー。0方向への切捨てと被除数と同符号の剰余 |
| シフト | `shift`, `shift_success_iff`, `oversized_left_is_zero` | 負数はエラー。幅以上を剰余でマスクしない。右シフトは符号を保つ |

`Value t` は整数値とその値域条件を持つ。`pack` は任意の数学的整数からこの値を作る。
値域保存はこの意味論内の性質であり、実コンパイラの型検査器が正しい入力を渡すことの
証明ではない。`quotient` は丸め前の整数を受け取る補助関数で、実際の型付け済み
演算に対応させる際は、両オペランドが共通型の値域内にあることも必要である。
`shift` の右辺も、元の整数型の解釈を終えた数学的整数を受け取る。

`Int.tdiv` / `Int.tmod` は除算・剰余に使用する。
算術右シフトには、正の2の冪による切下げ除算を使う。
この違いにより、`-7 / 3 = -2`、`-7 % 3 = -1`、`-7 >> 1 = -4` を区別する。
`i8` 最小値を `-1` で割った結果、u64 最大値の乗算、極端に大きいシフト数なども
具体的な定理として追加した。これらの具体例だけで全入力を証明したとは扱わない。

## 各処理系に残る対応証明

| 対象 | 実際の実装 | 残る義務 |
|---|---|---|
| jwc の型規則 | `jwc/ty.jw`: `bits`, `signed`, `widens_to`, `common` | 文字列による型名表現と `IntTy` の対応、不正な型名が到達しないこと、実関数の対応証明 |
| jwc の定数評価 | `jwc/ty.jw`: `CV`, `cv_add`, `cv_mul`, `cv_div` | 符号・大きさ・big 表現の対応。定数の警告・拒否規則。実行時の wrap と混同しない |
| jwc の型検査・lowering | `jwc/typeck.jw`, `jwc/lower.jw` | オペランドの共通型、暗黙変換、評価順序、IR の対応 |
| jwc の生成コード | `jwc/llvmfn.jw`: `binary`, `shift`、変換処理 | 生成された全命令列とLLVM意味論の対応。除数ゼロ・-1・シフト幅の分岐を含む |
| Rust の型規則 | `src/ast.rs`: `IntTy`、`src/types.rs` | `wrap`, `widens_to`, `common` とモデルの対応、型検査での使用箇所 |
| Rust の実行経路 | `src/interp.rs`: `binary`、`src/ir/exec.rs` | i128 の計算、とくに `wrapping_mul` と任意精度整数の剰余の対応 |
| Rust の生成コード | `src/ir/llvm.rs`: `binary`, `shift`、変換処理 | jwc と独立した生成コード対応、LLVMの未定義動作の排除 |
| 共通の実行環境 | `runtime/jw_rt.c`、clang、リンカ | エラー処理・ABI・最適化・最終バイナリへの対応 |

上の表は手動で調べた対応先であり、抽出器や証明器の代用ではない。
関数名、ソースハッシュ、テンプレート一致だけで義務を解消しない。
